# 每小时背词提醒

每小时提醒用户去背单词，并带上他当天的真实进度。

## 执行步骤

1. 用 bash 动态定位已授权的桌宠文件夹。会话名每次运行都不一样，不能写死路径：

```
for d in /sessions/*/mnt/*/; do [ -f "${d}app/nudge.py" ] && echo "$d"; done
```

没有输出就再试一层（用户可能把仓库放在了子目录里）：

```
ls -d /sessions/*/mnt/*/*/app/nudge.py 2>/dev/null | head -3
```

2. 进到找到的目录，执行提醒脚本：

```
cd "<找到的目录>" && python3 app/nudge.py
```

脚本会读取同目录下的 `config.json`、`data/state.json`、`wordbanks/` 里的词库，
自己判断当前时段、今日新词进度、待复习数量和连续打卡天数，打印 2-4 行提醒文字。

3. 把脚本输出**原样**作为这次运行的回复，不要改写措辞、不要加标题、不要加解释、
不要用 markdown 列表包装。可以在末尾另起一行补一句：打开桌宠面板，点「开始背词」。

4. 如果第 1 步找不到目录，或者脚本执行失败，只回这一句话然后结束：
「背词桌宠的文件夹没连上，需要在 Claude 里重新授权放 word-pet 的那个文件夹。」
不要尝试重建数据、不要新建文件、不要凭记忆编造进度数字。

## 约束

- 全程只读。绝对不要修改、覆盖或删除 `data/state.json` 和 `wordbanks/` 下的文件 ——
  背词进度只由桌宠面板负责写入，定时任务写进去会把进度冲掉。
- 不要创建任何新文件。
- 输出控制在 2-4 行。这是一条提醒，不是日报，不要写成报告格式。
- 时区按用户本地时区。
- 深夜时段脚本会自己换成"建议睡觉"的措辞，照原样输出即可，不要改成催促。
